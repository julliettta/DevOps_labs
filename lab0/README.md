# Lab0 — Notes Service

Простое веб-приложение "Заметки": форма для добавления записи и список 
уже сохранённых записей. Данные хранятся в PostgreSQL, а не в памяти — 
после перезагрузки страницы записи остаются на месте.

## Стек

- **Backend:** Python, Flask
- **Frontend:** HTML + JavaScript (fetch API)
- **База данных:** PostgreSQL (в Docker-контейнере)

## Как запустить

### 1. Поднять базу данных

Убедиться, что установлен Docker Desktop, затем выполнить:

```bash
docker run --name lab0-postgres -e POSTGRES_PASSWORD=pass -e POSTGRES_DB=lab0 -p 5432:5432 -d postgres
```

Проверить, что контейнер запущен:

```bash
docker ps
```

### 2. Установить зависимости

```bash
cd lab0/backend
pip install -r requirements.txt
```

### 3. Запустить приложение

```bash
python app.py
```

Приложение поднимется на `http://localhost:5000`

### 4. Проверить работу

1. Открыть `http://localhost:5000` в браузере
2. Ввести текст в поле и нажать "Добавить"
3. Перезагрузить страницу (F5) — запись должна остаться на месте, 
   так как она сохранена в базе данных, а не в памяти процесса
